**STUDENT ATTENDANCE MANAGEMENT SYSTEM**

**1. Project Title**
     STUDENT ATTENDANCE MANAGEMENT SYSTEM

**2. Requirement Gathering**
     Many educational institutions still manage attendance manually, which is time-consuming and prone to errors.
     The Student Attendance Management System provides a digital solution to record, monitor, and manage attendance efficiently.

**3. Objective Definition**

  *Automate attendance tracking.
  *Reduce manual errors.
  *Store attendance records securely.
  *Generate attendance reports instantly.
  *Improve attendance monitoring.
  *Provide user-friendly dashboard access.
  

**4. User & Module Identification**

**Users:**
  *Admin
  *Faculty
  *Student
**Modules:**
  *Admin Module
  *Manage Students
  *Manage Faculty
  *View Attendance Reports
**Faculty Module**
  *Mark Attendance
  *Edit Attendance
  *View Student Records
**Student Module**
  *View Attendance Percentage
  *View Attendance History
